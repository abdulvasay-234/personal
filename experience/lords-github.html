Case study / Institutional open source

LIET × GitHub

Helping students learn how developers build together.

I worked on introducing GitHub as part of an actual development workflow: version control, collaboration, contribution and public project work. The journey grew from introductory workshops into open-source experiences and structured institutional contribution workflows.

01 / The challenge

The starting point

Students were learning to code, but projects often stayed on individual machines. The challenge was to make collaboration, pull requests and review part of how students build.

02 / The approach

How the experience connects

The contribution workflow: students submit work, receive feedback and improve it before acceptance.

03 / Work done

From intent to execution

Introduce the fundamentals · 2022

Delivered a Git and GitHub workshop for 130 students, covering version control, collaboration, static websites, Linux command-line workflows and open-source participation.

Practice contribution · 2023

Through CodeWave Hub, Hacktoberfest introduced 250+ participants to repositories, web development and collaborative open-source contribution.

Deepen technical learning · 2024

Served as resource person for a Git/GitHub and open-source workshop reaching 116 students and eight faculty members.

Support institutional workflows

Worked around repository structure, contribution guidelines, project submissions and PR-based collaboration. The LIET organization provides a shared home for department repositories and student work.

04 / Impact

What the work enabled

Student practice

Exposure to branching, pull requests, code review and public portfolios.

Shared learning

Open-source activities gave students peers and support while learning to contribute.

Institutional continuity

Department repositories and structured submissions connect GitHub to ongoing academic and technical work.

05 / Reflection

What I took forward

The meaningful shift is from storing files online to participating in a development workflow. Review and iteration make collaboration a practical learning experience.
