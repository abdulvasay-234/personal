# Afnan Abdul Vasay — portfolio

A single-page editorial portfolio with subtle README-inspired details and a GitHub Campus Expert credential.

## Run locally

No build step is required. Start any static server from this directory:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Customize

- Replace the portrait, project, event, video, and blog placeholders with real images when available.
- Update social links directly in `index.html`.
- The site supports responsive layouts, keyboard navigation, and reduced-motion preferences.
